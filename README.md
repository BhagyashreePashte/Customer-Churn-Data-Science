# Customer Churn Analysis and Prediction Using Python

## 📌 Project Overview

This project analyzes customer churn using Python and the IBM Telco Customer Churn dataset.

The project follows an end-to-end Data Science workflow:

**Data Acquisition → Data Cleaning → Exploratory Data Analysis → Advanced Visualization → Statistical Analysis → Machine Learning → Recommendations**

## 🎯 Objectives

* Analyze customer churn patterns.
* Clean and preprocess customer data.
* Perform Exploratory Data Analysis (EDA).
* Create meaningful data visualizations.
* Identify factors associated with customer churn.
* Perform statistical hypothesis testing.
* Develop and evaluate machine learning models.
* Generate data-driven recommendations.

## 🗂️ Dataset

The project uses the IBM Telco Customer Churn dataset.

The dataset contains customer information including:

* Demographics
* Tenure
* Services
* Contract type
* Payment method
* Monthly charges
* Total charges
* Churn status

After cleaning, the Week 1 dataset contains **7,032 records and 21 variables**.

## 🔍 Week 1 — Data Acquisition, Cleaning and EDA

Week 1 focused on:

* Dataset acquisition
* Data inspection
* Missing-value handling
* Data-type conversion
* Duplicate checking
* Exploratory data analysis
* Data visualization
* Correlation analysis

### Key Findings

* 73.42% of customers did not churn.
* 26.58% of customers churned.
* Average tenure:

  * Non-churned: 37.65 months
  * Churned: 17.98 months
* Average monthly charges:

  * Non-churned: 61.31
  * Churned: 74.44
* Month-to-month contracts showed a substantially larger share of churn than one-year and two-year contracts.
* Tenure and TotalCharges had a correlation of 0.83.
